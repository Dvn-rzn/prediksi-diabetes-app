# 🩺 Aplikasi Prediksi Risiko Diabetes

Aplikasi berbasis Web dan Machine Learning untuk menganalisis estimasi risiko diabetes berdasarkan indikator kesehatan pribadi.

🚀 **Coba Aplikasi Web Secara Langsung:**
[Klik di sini untuk membuka Web Prediksi Diabetes](https://prediksi-diabetes-app.streamlit.app) *(Ganti dengan URL Streamlit kamu)*

## 🛠️ Fitur Utama
- Input indikator kesehatan fisik & riwayat medis sederhana
- Model Machine Learning (XGBoost/Random Forest)
- Visualisasi persentase estimasi risiko yang intuitif
- Antarmuka interaktif menggunakan Streamlit
